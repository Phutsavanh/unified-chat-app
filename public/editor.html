ສື່ຂອງໂປຣເຈັກ

ກົດ + ຫຼື ລາກໄຟລ໌ລົງ timeline. ໄຟລ໌ຢູ່ໃນເຄື່ອງຂອງທ່ານເທົ່ານັ້ນ, ບໍ່ໄດ້ອັບໂຫຼດ.

ສຽງ ແລະ ເພງ

ເພງສ້າງຂຶ້ນໃນໂປຣແກຣມ — ໃຊ້ໄດ້ຟຣີ ບໍ່ຕິດລິຂະສິດ. ກົດ ▶ ເພື່ອຟັງ, + ເພື່ອເພີ່ມທີ່ເສັ້ນເວລາ.

ຈາກ Openverse: ສະເພາະໄຟລ໌ CC0 / ສາທາລະນະ / CC BY. ໄຟລ໌ CC BY ຕ້ອງໃສ່ເຄຣດິດ (ໂປຣແກຣມສະແດງໃຫ້ຕອນສົ່ງອອກ).

ສະຕິກເກີ

ລາກສະຕິກເກີໃນຈໍເພື່ອຍ້າຍ, ປັບຂະໜາດ/ໝູນ/ແອນິເມຊັນໄດ້ທາງຂວາ.

ເອັບເຟັກວິດີໂອ

ເອັບເຟັກຖືກເພີ່ມທີ່ເສັ້ນເວລາ (3 ວິ). ລາກຂອບໃນ timeline ເພື່ອປັບຄວາມຍາວ.

ແປຊັບ (AI)

ພາສາຕົ້ນສະບັບ = "ພາສາທີ່ເວົ້າໃນວິດີໂອ" ຂ້າງເທິງ. ແປຊ້ຳໄດ້, ຄຳແປເກົ່າຈະຖືກແທນທີ່.

ຈັດເວລາຊັບຈາກບົດ ບໍ່ໃຊ້ AI

ວາງບົດເວົ້າພາສາລາວ ແລ້ວໂປຣແກຣມຈະຈັບຈັງຫວະສຽງເວົ້າ ແລະ ວາງຊັບໃຫ້ອັດຕະໂນມັດ. ຖ້າປະວ່າງ ຈະສ້າງຊ່ອງວ່າງຕາມສຽງເວົ້າໃຫ້ພິມເອງ.

ຕັ້ງຄ່າ AI

ການສ້າງຊັບ ແລະ ແປຊັບດ້ວຍ AI ໃຊ້ OpenAI (Whisper ຮອງຮັບພາສາລາວ). ສ້າງ API Key ໄດ້ທີ່ platform.openai.com (ຄ່າໃຊ້ຈ່າຍປະມານ $0.006 ຕໍ່ນາທີ). Key ຖືກເກັບໄວ້ທີ່ເຊີບເວີເທົ່ານັ້ນ.

ໃຊ້ Key ຈາກ environment variable OPENAI_API_KEY ຢູ່.

ສຽງພາກລາວ (Microsoft Azure Speech)

ມີສຽງລາວແທ້ 2 ສຽງ (ຍິງ/ຊາຍ). ສ້າງ Speech resource ທີ່ portal.azure.com ແລ້ວເອົາ Key ແລະ Region ມາໃສ່. ແຜນຟຣີໃຊ້ໄດ້ 500,000 ຕົວອັກສອນ/ເດືອນ.

ບໍ່ມີ Key? ໃຊ້ "ຈັດເວລາຊັບຈາກບົດ" ທີ່ເຮັດວຽກໃນເຄື່ອງໄດ້ເລີຍ.
